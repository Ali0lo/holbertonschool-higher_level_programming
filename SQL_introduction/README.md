# MySQL Sandbox

## Description
This repository contains SQL scripts to interact with a MySQL server.

### Usage:
1. **List Databases**: The `0-list_databases.sql` script lists all databases available on the server.
2. **Database Creation**: You can create additional databases using SQL commands.
3. **Expected Output**:
   - The initial output shows the default databases like `information_schema`, `mysql`, etc.
   - After creating new databases, the list will reflect those changes.

### Notes:
- SQL keywords are written in uppercase for consistency.
